# «Сгореть нельзя остановиться»: семь стихотворений живых поэтов. 18+

*Видео*

**link:** https://novayagazeta.ru/articles/2018/06/02/76697-ostatsya-v-zhy

«Резкие, непричесанные, зато настоящие», — так редактор Андрей Орловский описывает стихи сборника «Живые поэты». 26 мая молодые авторы проекта устроили поэтическую неформальную сходку. Неожиданно она оказалась массовой. Леха Никонов, Андрей Орловский, Егор Сергеев, Роман Мнацаканов, Дмитрий Воденников, Евгений Горон и другие поэты из разных городов читали свои стихи вживую. Поэзия становится модной. Мы выбрали для вас семь ярких читок.
