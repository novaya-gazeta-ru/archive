# Минцифры предложило разрешить бизнесу обезличивать данные россиян без их согласия

Минцифры представило к третьему чтению поправки, разрешающие бизнесу обезличивать данные россиян без их согласия. С документом [ознакомился](https://www.kommersant.ru/doc/4828970) «Коммерсант». Согласно поправкам, обезличенные данные компании будут передавать государству «для государственного и муниципального управления» — информацию будут использовать для разработки сервисов искусственного интеллекта. Документ предполагает и ряд исключений: без согласия нельзя будет обезличивать данные силовиков, судей, свидетелей, потерпевших и иных участников уголовного судопроизводства. Согласно законопроекту, начать работу с ними можно будет лишь спустя три года после обезличивания. По данным экспертов издания, обезличивание данных без получения согласия упростит бизнесу работу с данными.
