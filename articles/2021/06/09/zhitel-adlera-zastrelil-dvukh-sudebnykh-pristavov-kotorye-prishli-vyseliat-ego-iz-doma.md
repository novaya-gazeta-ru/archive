# Житель Адлера застрелил двух судебных приставов, которые пришли выселять его из дома

Житель Адлерского района Сочи открыл огонь по двум сотрудникам Федеральной служба судебных приставов, которые пришли выселять его из дома. Об этом «Интерфаксу» [рассказали](https://www.interfax.ru/russia/771325) в УВД Сочи.

> «Двое судебных приставов пришли выселять семью из дома по решению Адлерского суда. Хозяин взял охотничье ружье и застрелил их насмерть»,

— цитирует агентство правоохранителей. По данным источника агентства, стрелок — 61-летний Вартан Кочиян. Приставы — Андроник Мативосян и Альберт Агозян — пришли к нему, чтобы исполнить решение о сносе самостроя. Злоумышленника уже задержали правоохранители. Сопротивления он не оказывал.
