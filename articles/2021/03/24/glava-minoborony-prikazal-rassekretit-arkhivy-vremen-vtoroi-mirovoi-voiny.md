# Глава Минобороны приказал рассекретить архивы времен Второй мировой войны

Министр обороны Сергей Шойгу распорядился рассекретить военные архивы времен Второй мировой войны. Это следует из его приказа, [опубликованного](https://t.me/rian_ru/87674) агентством РИА Новости.

Экспертные комиссии минобороны до 2023 года должны будут проанализировать крупный корпус документов, созданных Генштабом Красной Армии, наркомом Военно-Морского флота, войсками тыла, учебными заведениями, кадровыми органами, военными госпиталями и санчастями.

Таким образом, перечень рассекреченных документов расширится. Сейчас в доступе у исследователей есть рассекреченный архив Красной Армии и Военно-морского флота за период с 1941 по 1945 год. С помощью них историки смогли обновить данные о потерях СССР в ходе войны с Германией.

Гриф «секретно» с военных архивов того времени сняли в 2007 году по приказу предшественника Шойгу Анатолия Сердюкова. В ноябре документ [признали](http://publication.pravo.gov.ru/Document/View/0001202103220036) утратившим силу.
