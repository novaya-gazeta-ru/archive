# Российским вузам со следующего учебного года разрешили проводить сессии дистанционно с использованием биометрии

Премьер-министр России Михаил Мишустин подписал постановление, разрешающее вузам в следующем учебном году проводить сессии дистанционно с использованием Единой биометрической системы. Документ [опубликовали](http://government.ru/news/41688/) на сайте правительства. Сдавать сессии дистанционно смогут студенты, которые обучаются по программам бакалавриата, специалитета и магистратуры. Решение о таком формате будет принимать руководство вузов. Для сдачи экзамена студенты должны будут сначала зарегистрироваться в системе, а перед началом — пройти процедуру прокторинга (произнести перед камерой случайные числа). После этого система оценит и запомнить поведение пользователя, а затем — отправит данные в вуз. При подтверждении личности студента допустят до экзамена. Минобрнауки [разрешило](https://web.archive.org/web/*/https://novayagazeta.ru/news/2021/01/29/167480-minobrnauki-razreshilo-vuzam-vernutsya-k-ochnomu-obucheniyu-s-8-fevralya) подведомственным вуза вернуться к очному обучению с 8 февраля с соблюдением санитарных норм. Студенты высших учебных заведений до этого (с середины ноября) учились дистанционно из-за распространения коронавируса. Весной занятия тоже проходили в дистанционном формате. Переход на «дистанционку» вызвал претензии у некоторых студентов, обучающихся на платной основе. Они требовали снизить стоимость обучения, мотивируя это снижением качества получаемых знаний из-за регулярных технических сбоев.
