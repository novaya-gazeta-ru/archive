# На GitHub составили протокол, так как сервис не удалил списки «Умного голосования»

В Мировой суд Москвы поступил протокол об административном правонарушении в отношении веб-сервиса GitHub, [пишет](https://www.interfax.ru/russia/806188) «Интерфакс».

В суде агентству [уточнили](https://www.interfax.ru/russia/806202), что поводом для составления протокола стало то, что сервис не удалил списки «Умного голосования». GitHub вменяется в вину ч.2 ст. 13.41 КоАП РФ (неудаление владельцем в интернете информации, если обязанность по ее удалению предусмотрена законодательством РФ). По ней сервису грозит до 4 млн рублей штрафа, заседание пройдет 23 декабря.

В августе Роскомнадзор направил письма с требованием к [Apple](2021/08/19/roskomnadzor-potreboval-udalit-iz-app-store-prilozhenie-navalnogo-news.md) и [Google](2021/08/20/roskomnadzor-potreboval-udalit-iz-google-play-prilozhenie-navalnogo-news.md) удалить приложение «Навальный», где публикуются списки «Умного голосования». «Упомянутое приложение используется для продолжения деятельности и проведения мероприятий экстремистской организации. Наказания за упомянутые деяния предусмотрены ст. 282.2 УК РФ», — заявили в ведомстве, [добавив](2021/09/02/roskomnadzor-otkaz-apple-i-google-ot-udaleniia-prilozheniia-navalnogo-budet-rastsenivatsia-kak-vmeshatelstvo-v-rossiiski.md), что отказ Google и Apple будет считаться вмешательством в российские выборы. После этого IT-гиганты [удалили](https://web.archive.org/web/*/https://novayagazeta.ru/articles/2021/09/17/google-i-apple-udalili-prilozhenie-navalnyi-iz-magazinov-news) приложение, в октябре Google [вернула](2021/10/09/prilozhenie-navalnogo-vernuli-v-google-play-dlia-rossiiskikh-polzovatelei-news.md) для пользователей из России в Google Play приложение Навального.

Помимо этого, в дни голосования по выборам в Госдуму сервис для обмена документами Google Docs [заблокировал](https://web.archive.org/web/*/https://novayagazeta.ru/hyper/%C2%AB%C2%AB%C2%AB [https://novayagazeta.ru/articles/2021/09/19/google-docs-zablokiroval-faily-s-rekomendatsiiami-umnogo-golosovaniia-news%C2%BB%C2%BB%C2%BB](https://web.archive.org/web/*/https://novayagazeta.ru/articles/2021/09/19/google-docs-zablokiroval-faily-s-rekomendatsiiami-umnogo-golosovaniia-news%C2%BB%C2%BB%C2%BB)) файлы с рекомендациями «Умного голосования», предварительно обратившись к сторонникам Навального с требованием удалить их. С этим требованием к сервису Google Docs обратился Роскомнадзор. Также 18 сентября YouTube по требованию российских властей [удалил](2021/09/18/roskomnadzor-potreboval-ot-youtube-udalit-tri-rolika-s-kanala-navalnogo-so-spiskami-umnogo-golosovaniia-news.md) с канала Алексея Навального несколько роликов со списками «Умного голосования».
