# ЦБ разработал план по борьбе с мошенничеством. Среди предложенных мер — гарантированный возврат при кражах со счетов

Центральный Банк России (ЦБ) разработал план поправок к 61-ФЗ «О национальной платежной системе», который должен обезопасить жертв мошенничества. С текстом документа [ознакомился](https://www.rbc.ru/finances/06/12/2021/61a8d4639a79476b808c4eee?from=from_main_1) РБК.

- ЦБ планирует определить конкретную сумму компенсации жертвам мошенников и упростить порядок ее получения. Запрос на возврат украденных средств клиент банка должен будет подать не позднее следующего дня после осуществления перевода. При этом, банкам с низким уровнем механизма по предотвращению хищений придется вернуть всю сумму целиком вне зависимости от ее размера.
- Регулятор также хочет дать банкам право списывать деньги по тем операциям, которые кажутся мошенническими, только через один-два дня несмотря на согласие клиента. За это время, считают в Банке России, люди успеют осознать, что их обманули, и отменят операцию.
- Центральный Банк предлагает дать банкам право на пять дней блокировать средства на счету получателя перевода, если тот окажется в созданной ЦБ базе данных cо случаями подозрительных операций. «Указанный срок необходим клиенту-потерпевшему, правоохранительным органам для обращения в суд для получения законного основания дальнейшего ареста денежных средств и получения судебного решения о возврате денег», — говорится в документе.
- ЦБ планирует обязать банки с обеих сторон — отправителя и получателя — проверять операции на признаки мошенничества.

Введение гарантированный сумму выплаты в результате мошеннических действий может потенциально увеличить число обращений от недобросовестных клиентов банка, которые будут оспаривать старые банковские переводы, считает Директор департамента информационной безопасности Росбанка Михаил Иванов.

Советник по специальным проектам коллегии адвокатов А1 Сергей Демкин отмечает, что сейчас мошеннические переводы происходят в основном по вине доверчивых клиентов. Он считает, что ЦБ необходимо разработать более четкий план по идентификации потенциальных мошенников.

По мнению руководителя направления по противодействию онлайн-мошенничеству Group-IB Павла Крылова, заморозка переводов на один-два дня — это хорошая идея с точки зрения механизма по предотвращению хищений, но она может вызвать трудности у добросовестных клиентов, чьи операции по ошибке сочли мошенническими.
