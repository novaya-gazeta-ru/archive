# Госдума одобрила законопроект о введении Fan ID для посещения спортивных мероприятий

Государственная дума в третьем, финальном чтении одобрила законопроект о введении «паспортов болельщиков» — Fan ID —для посещения спортивных мероприятий. Об этом [сообщается](http://duma.gov.ru/news/53032/) на сайте ГД.

Согласно новому законодательству, Fan ID можно будет оформить на портале Госуслуги. Этот документ нужен дня «идентификации зрителей», без него больше не будут продавать билеты на соревнования и другие спортивные мероприятия. Fan ID будет хранить в себе информацию о действиях владельцев.

Правительству еще предстоит определить точный перечень мероприятий, для посещения которых необходимо будет завести Fan ID, уточняется в сообщении.

Закон о введении «паспортов болельщиков» вступит в силу 1 июня 2022 года при условии, что его одобрят в Совете Федерации.
