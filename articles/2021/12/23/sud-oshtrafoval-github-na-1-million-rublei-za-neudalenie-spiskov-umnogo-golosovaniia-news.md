# Суд оштрафовал GitHub на 1 миллион рублей за неудаление списков «Умного голосования»

Мировой суд Таганского района Москвы оштрафовал веб-сервис GitHub на 1 млн рублей за неудаление запрещенной информации. Об этом [сообщает](https://t.me/moscowcourts/914) телеграм-канал московских судов.

GitHub признали виновным по ч. 2 ст. 13.41 КоАП (нарушение порядка ограничения доступа к информации). В начале декабря на сервис [составили](2021/12/02/na-github-sostavili-protokol-tak-kak-servis-ne-udalil-spiski-umnogo-golosovaniia-news.md) протокол из-за того, что тот не удалил списки «Умного голосования».

В августе Роскомнадзор направил письма с требованием к [Apple](2021/08/19/roskomnadzor-potreboval-udalit-iz-app-store-prilozhenie-navalnogo-news.md) и [Google](2021/08/20/roskomnadzor-potreboval-udalit-iz-google-play-prilozhenie-navalnogo-news.md) удалить приложение «Навальный», где публикуются списки «Умного голосования». «Упомянутое приложение используется для продолжения деятельности и проведения мероприятий экстремистской организации. Наказания за упомянутые деяния предусмотрены ст. 282.2 УК РФ», — заявили в ведомстве, [добавив](2021/09/02/roskomnadzor-otkaz-apple-i-google-ot-udaleniia-prilozheniia-navalnogo-budet-rastsenivatsia-kak-vmeshatelstvo-v-rossiiski.md), что отказ Google и Apple будет считаться вмешательством в российские выборы.

Через месяц IT-гиганты удовлетворили запрос регулятора и [удалили](https://web.archive.org/web/*/https://novayagazeta.ru/articles/2021/09/17/google-i-apple-udalili-prilozhenie-navalnyi-iz-magazinov-news) приложение, а в октябре в Google Play [вернули](2021/10/09/prilozhenie-navalnogo-vernuli-v-google-play-dlia-rossiiskikh-polzovatelei-news.md) его для российских пользователей.
