# Канал «Навальный LIVE» оказался недоступен на YouTube

Канал «Навальный LIVE» оказался недоступен на YouTube.

*Скрин: канал «Навальный LIVE»*

Леонид Волков сообщил в разговоре с «Новой газетой», что команда Навального разбирается в произошедшем.

Спустя некоторое время канал снова стал доступен на YouTube. По словам Волкова, канал не блокировали. «Просто какой-то глюк, сбой», — заявил он.

Как [сообщается](https://t.me/navalnylivechannel/4070) в телеграм-канале «Навальный LIVE», некоторым пользователям пришли сообщения об отключении функции «Спонсорства».

**Читайте также:** https://novayagazeta.ru/articles/2021/09/09/po-doroge-v-shatdaun

Несколько дней назад YouTube по требованию российских властей [удалил](https://novayagazeta.ru/articles/2021/09/18/roskomnadzor-potreboval-ot-youtube-udalit-tri-rolika-s-kanala-navalnogo-so-spiskami-umnogo-golosovaniia-news) с канала Навального несколько роликов со списками «Умного голосования». Помимо этого, основатель Telegram Павел Дуров [заявил](https://novayagazeta.ru/articles/2021/09/17/my-schitaem-etu-praktiku-legitimnoi-pavel-durov-obiavil-o-blokirovke-bota-umnogo-golosovaniia-v-telegrame-obiasniv-eto-dniami-tishiny-news), что мессенджер ограничит работу ботов, связанных с предвыборной агитацией с полуночи 18 сентября, после чего бот «Умного голосования» был заблокирован. Вскоре бот разблокировали для пользователей с иностранными номерами. Также пользователи из России [сообщали](https://novayagazeta.ru/articles/2021/09/15/v-rossii-zafiksirovana-blokirovka-google-docs-eto-proizoshlo-posle-publikatsii-tam-spiskov-umnogo-golosovaniia-news) о блокировке Google Docs после публикации там списков «Умного голосования».

В августе Роскомнадзор направил письма с требованием к [Apple](https://novayagazeta.ru/articles/2021/08/19/roskomnadzor-potreboval-udalit-iz-app-store-prilozhenie-navalnogo-news) и [Google](https://novayagazeta.ru/articles/2021/08/20/roskomnadzor-potreboval-udalit-iz-google-play-prilozhenie-navalnogo-news) удалить приложение «Навальный», где публикуются списки «Умного голосования», так как, по мнению ведомства, приложение используется для «продолжения деятельности и проведения мероприятий экстремистской организации».

*Обновлено 21:30. Добавлена информация о возможном отключении «спонсорства»*
