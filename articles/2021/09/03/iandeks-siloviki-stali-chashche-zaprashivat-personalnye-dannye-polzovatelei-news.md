# «Яндекс»: силовики стали чаще запрашивать персональные данные пользователей

Количество государственных запросов на предоставление персональных данных пользователей сервисов «Яндекса» растет с каждым годом. Это [следует](https://yandex.ru/company/privacy/transparencyreport) из публичного отчета IT-компании.

С января по июнь 2021 года компания получила **на 21,5% больше** запросов о предоставлении персональных данных пользователей по сравнению с этим же периодом в прошлом году. При этом 21% запросов «Яндекс» отклонил.

В «Яндексе» настаивают, что предоставляют органами государственной власти «ровно столько информации, сколько необходимо для ответа». Компания заявляет, что отклоняет все запросы, которые поступают по неофициальным каналам, например по телефону или по электронной почте.

В рамках рассмотрения дела против полицейских, подбросивших наркотики Ивану Голунову, [выяснилось](https://thebell.io/po-zvonku-ili-po-zaprosu-kak-yandeks-taksi-vydaet-politsii-dannye-polzovatelej), что сервис «Яндекс.Такси» предоставил силовикам информацию о передвижениях журналиста. Сам Голунов [утверждал](https://teleg.run/GolunovForever/565), что запрос от полицейских был некорректный, и один из сотрудников направил в компанию письмо с электронной почты Mail.ru. Тогда глава пресс-службы «Яндекс.Такси» [заявил](http://(https://www.facebook.com/vladimir.isaev/posts/2973086259397949?comment_id=2973179006055341&reply_comment_id=2973219016051340), что в юридический отдел компании поступил «бумажный запрос, оформленный по всем правилам».

В июне 2021 года компания запустила сервис «Яндекс ID», с помощью которого пользователи могут просматривать всю накопленную о себе информацию. В отчете утверждается, что сервис позволяет скачивать и удалять эту информацию.

По данным «Яндекса», с момента запуска инструмента от пользователей поступило 54 885 запросов на удаление данных. Отмечается, что один пользователь мог создать несколько запросов.

В отчете также представлены данные по запросам, связанным с «правом на забвение», согласно которому пользователи могут требовать удаление недостоверной или незаконной информации о себе из результатов поиска. Всего «Яндекс» проанализировал запросы по трем основаниям — неактуальность, недостоверность и нарушение закона. По сравнению с первым полугодием прошлого года **почти на 40% выросло число запросов об удалении информации, связанной с нарушением закона.**

В запросах об удалении недостоверной информации по «праву на забвение» компания, как правило, отказывает — **77% из 3069 требований не удовлетворены.Больше половины (58%) из **4405 запросов по неактуальной по мнению пользователя информации **также отклонены.**
