# Google Docs заблокировал файлы с рекомендациями «Умного голосования»

Сервис для обмена документами Google Docs заблокировал файлы с рекомендациями «Умного голосования». Об этом в своем твиттере [сообщил](https://twitter.com/fbkinfo/status/1439362914612400132) сторонник политика Алексея Навального и бывший директор Фонда борьбы с коррупцией* Иван Жданов.

*\*

Оба текстовых документа, распространенных командой Навального, теперь недоступны в России, они открываются лишь через VPN.

С требованием заблокировать файлы к сервису Google Docs ранее обратился Роскомнадзор.

Накануне YouTube по требованию регулятора удалил два видеоролика с канала, где есть списки кандидатов. Роскомнадзор заявил, что видео необходимо заблокировать из-за призывов «к осуществлению экстремистской деятельности». Также о блокировке бота «Умного голосования» в Telegram объявил и основатель мессенджера Павел Дуров.

В августе Роскомнадзор направил письма с требованием к [Apple](https://novayagazeta.ru/articles/2021/08/19/roskomnadzor-potreboval-udalit-iz-app-store-prilozhenie-navalnogo-news) и [Google](https://novayagazeta.ru/articles/2021/08/20/roskomnadzor-potreboval-udalit-iz-google-play-prilozhenie-navalnogo-news) удалить приложение «Навальный», где публикуются списки «Умного голосования». «Упомянутое приложение используется для продолжения деятельности и проведения мероприятий экстремистской организации. Наказания за упомянутые деяния предусмотрены ст. 282.2 УК РФ», — заявили в ведомстве, [добавив](https://novayagazeta.ru/articles/2021/09/02/roskomnadzor-otkaz-apple-i-google-ot-udaleniia-prilozheniia-navalnogo-budet-rastsenivatsia-kak-vmeshatelstvo-v-rossiiskie-vybory-news), что отказ Google и Apple будет считаться вмешательством в российские выборы.
