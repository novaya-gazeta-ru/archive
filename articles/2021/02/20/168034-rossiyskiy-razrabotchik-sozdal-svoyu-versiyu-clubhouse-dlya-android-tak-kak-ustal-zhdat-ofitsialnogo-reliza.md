# Российский разработчик создал свою версию Clubhouse для Android, так как устал ждать официального релиза

Разработчик из Петербурга Григорий Клюшников создал неофициальное приложение Clubhouse для системы Android. Об этом он сообщил в своем твиттере.

Приложение [можно скачать](https://github.com/grishka/Houseclub) в виде APK-файла на GitHub и установить его на устройство. Разработчики могут импортировать приложение в Android Studio. В неофициальной версии нет возможности модерации бесед, также пользователь не может получать уведомления.

Разработка заняла у Клюшникова полтора дня. В описании приложения сказано, что его разработка — «скорее вынужденная мера до того, как Clubhouse выпустит свое официальное приложение для Android».

Clubhouse — новая социальная сеть, где пользователи обмениваются голосовыми сообщениями в онлайн-комнатах в режиме реального времени. Чтобы зарегистрироваться в приложении, нужно получить приглашение («инвайт») от уже существующего пользователя или дождаться своей очереди. За две недели февраля количество загрузок Clubhouse [выросло](https://novayagazeta.ru/news/2021/02/19/167989-clubhouse) с 3,5 млн до 8,1 млн. Официально приложение пока доступно для пользователей iOS.
