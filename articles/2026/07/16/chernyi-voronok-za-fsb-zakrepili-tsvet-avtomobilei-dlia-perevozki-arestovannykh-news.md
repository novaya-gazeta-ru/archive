# Черный «воронок»: за ФСБ закрепили цвет автомобилей для перевозки арестованных

Правительство утвердило требования к автомобилям, которые ФСБ использует для перевозки заключенных под стражу, [пишет](https://tass.ru/obschestvo/27917637) ТАСС со ссылкой на документ, с которым ознакомилось госагентство.

> Черный — это «основной цвет наружной поверхности транспортных средств», указали в правительстве. На машине должна присутствовать надпись «ФСБ России» или «Пограничная служба ФСБ России», эмблема структуры и контрастные полоски — белые, синие или красные

Помимо этого, на машинах ФСБ можно размещать мигалки.

Согласно [ГОСТу](https://allgosts.ru/03/220/gost_r_50574-2019), у ФСБ есть несколько цветов автомобилей для разных случаев:

-

черный с полосками цвета триколора — для машин, которые используются антитеррористическими подразделениями;

-

серый, желтый, зеленый с синей полосой — для служб по разминированию;

-

зеленый, светло-серый, черный с сине-зеленой полосой — для пограничных подразделений ФСБ.
