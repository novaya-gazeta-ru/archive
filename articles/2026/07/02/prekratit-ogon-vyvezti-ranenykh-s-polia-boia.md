# Прекратить огонь! Вывезти раненых с поля боя!

*Обращение от имени читателей «Новой газеты», которое можно подписать*

> 18+. НАСТОЯЩИЙ МАТЕРИАЛ (ИНФОРМАЦИЯ) ПРОИЗВЕДЕН, РАСПРОСТРАНЕН И (ИЛИ) НАПРАВЛЕН ИНОСТРАННЫМ АГЕНТОМ МУРАТОВЫМ ДМИТРИЕМ АНДРЕЕВИЧЕМ ЛИБО КАСАЕТСЯ ДЕЯТЕЛЬНОСТИ ИНОСТРАННОГО АГЕНТА МУРАТОВА ДМИТРИЯ АНДРЕЕВИЧА.

Президенту России Владимиру Путину. Президенту Украины Владимиру Зеленскому.

Господа президенты!

Характер боевых действий на российско-украинском фронте с использованием беспилотных летательных аппаратов не дает возможности эвакуировать десятки раненых с поля боя.

Женевские соглашения по их спасению не соблюдаются.

Эвакуационные команды попадают под огонь при попытках вывезти раненых и убитых.

Путь к миру может начинаться по-разному. Мы предлагаем для начала прекратить огонь для вывоза тел (близится аномальная жара) и спасения раненых — многие остаются без помощи по несколько дней и даже недель.

Мы также обращаемся к IT-компаниям с просьбой обеспечить мониторинг за прекращением огня с помощью систем видеонаблюдения.

Этот акт гуманизма, надеемся, будет поддержан гражданами обеих стран и станет шагом к мирному процессу.
