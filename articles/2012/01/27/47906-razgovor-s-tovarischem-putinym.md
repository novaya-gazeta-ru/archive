# Разговор с товарищем Путиным

*[media: <br>
	&nbsp;]*

*[media: <br>
	<em>День отошел,</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;как предчувствие смутен,</em>]*

*[media: <em>Солнца луч догорел в окне.</em>]*

*[media: <em>Двое в комнате — я и Путин.</em>]*

*[media: <em>И кто из нас кто — непонятно&nbsp;</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; мне.</em>]*

*[media: <em>За эти годы</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp;он стал, по сути,</em>]*

*[media: <em>Моим альтер эго,</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; меня не спросясь.</em>]*

*[media: <em>Мое подсознанье</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; опутал Путин,</em>]*

*[media: <em>Вступивши с ним</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;в преступную связь.</em>]*

*[media: <em>&nbsp;Облик его —</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; величавый и строгий,</em>]*

*[media: <em>Взгляд — внимательный,</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; как у врача,</em>]*

*[media: <em>Напомнил мне с детства</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; любимые строки</em>]*

*[media: <em>Другого</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; Владимир Владимирыча.</em>]*

*[media: <em>&nbsp;И я на стул,</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; подстелив газету,</em>]*

*[media: <em>Чтобы обивку</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; его сберечь,</em>]*

*[media: <em>Встал,</em>]*

*[media: <em>&nbsp; &nbsp; и позу приняв поэта,</em>]*

*[media: <em>Начал такими&nbsp;</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;словами</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; речь:</em>]*

*[media: <em>«Товарищ Путин,</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;я вам докладываю,</em>]*

*[media: <em>Не по службе,</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;а по душе.</em>]*

*[media: <em>Душе населения,</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; что когда-то</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;вы радовали,</em>]*

*[media: <em>Но если честно,</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;не радуете уже.</em>]*

*[media: <em>&nbsp;Владимир Владимирыч,</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; обращаюсь к вам редко, ваше время</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; безмерно ценя,</em>]*

*[media: <em>Но есть такой овощ —</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;горькая редька...</em>]*

*[media: <em>Надеюсь, &nbsp;поняли вы меня.</em>]*

*[media: <em>Товарищ Путин,</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; по фабрикам дымным,</em>]*

*[media: <em>По фермам бесчисленным</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;всех мастей</em>]*

*[media: <em>Вашим,</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp;когда-то любимым,</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;именем</em>]*

*[media: <em>Мамаши сегодня</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; пугают детей.</em>]*

*[media: <em>Владимир Владимирыч,</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;как Золушке с бала,</em>]*

*[media: <em>Когти рвать вам</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;пришла пора.</em>]*

*[media: <em>Ботекс бессилен —</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; ваше хлебало</em>]*

*[media: <em>Заколебало электорат.</em>]*

*[media: <em>&nbsp;Товарищ Путин,</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;прошу вас слезно —</em>]*

*[media: <em>&nbsp;Пока работают тормоза...</em>]*

*[media: <em>&nbsp;Товарищ Путин,</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;пока не поздно...»</em>]*

*[media: <em>Я прорыдал</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; и открыл глаза.</em>]*

*[media: <em>&nbsp;...Ночь за окном,</em>]*

*[media: <em>&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; черный воздух мутен,</em>]*

*[media: <em>Милая Русь</em>]*
