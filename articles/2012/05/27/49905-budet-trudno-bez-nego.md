# Будет трудно без него

*Ушел из жизни выдающийся ученый, полонист и полонофил, наш большой друг профессор В.А. Хорев.*

Не стало замечательного, любимого друзьями, коллегами и учениками человека, деятельного ученого, воспитавшего несколько поколений полонистов, сделавшего очень многое для дружбы российской и польской науки. Нам будет трудно без него.

Выражаем глубокое соболезнование всем близким покойного.

**Польский культурный центр в Москве**
