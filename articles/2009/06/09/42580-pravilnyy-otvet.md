# Правильный ответ

В одном из крупнейших московских вузов недавно прошла олимпиада по обществоведению для школьников.

Из списка тестовых вопросов мы выбрали только один (с теми вариантами ответов, которые к нему прилагались). Предлагаем вам, во-первых, отметить правильный ответ, а во-вторых, обсудить сами формулировки.

*Назовите характеристики политической системы современного российского общества:*

*А) опора политической системы на государственную религию;Б) отказ доминирования одной официальной партийно-государственной идеологии и установление принципа идеологического плюрализма;В) опора политической системы на многоукладную экономику, проявляющуюся в различных формах собственности;Г) следование конституционному принципу суверенной демократии;Д) наличие в структуре политической системы российского общества политической оппозиции.*

Необходимые пояснения: правильный ответ – только один; через несколько дней сравним ваши варианты с правильным.
