# Преподаватель лучшей школы России об отмене тестовой части ЕГЭ по русскому языку

Сергей Иванов, преподаватель лицея №1535, признанного в 2014 году лучшей школой России, — о том, с чем, по его мнению, связано решение Минобразования изъять тестовую часть из ЕГЭ по русскому языку, как изменится школьная подготовка и чего стоит ожидать школьникам и их родителям.
