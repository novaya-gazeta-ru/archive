# Фестиваль More Amore 2014 в саду «Эрмитаж»

26 июля в саду «Эрмитаж» в Москве прошел 6-ой по счету летний фестиваль More Amore. В этому году на сцене феста выступили Павел Артемьев, группа Rekevin и Алина Орлова с Baltic Light Orchestra под руководством дирижера Александраса Шимелиса.
