# Евгений Ясин о решении суда по делу ЮКОСа

Научный руководитель Высшей школы экономики комментирует приговор по делу ЮКОСа. В рамках комментария обсудили две темы: можно ли говорить о политических мотивах при вынесении приговора и кто в итоге будет выплачивать эти 50 млрд долларов.
