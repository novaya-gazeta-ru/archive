# Как читатели «Новой» собирали помощь детям Луганска (ФИЛЬМ)

*Акция «Только детский размер!»*

В течение двух дней читатели «Новой газеты» несли в редакцию гуманитарную помощь для луганских детей. 28 ноября журналисты «Новой» отправили ее по назначению.
