# Солнце светит для всех одинаково?

*«Великостишия» Сергея Мостовщикова, иллюстрации Петра Саруханова*

Солнце светит для всех одинаково\
 И, казалось бы, весь этот свет\
 Ежедневно доступен для каждого,\
 Но на деле выходит, что нет.
