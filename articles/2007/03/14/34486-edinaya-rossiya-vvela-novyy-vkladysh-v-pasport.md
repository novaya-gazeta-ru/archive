# «Единая Россия» ввела новый вкладыш в паспорт

Во время предвыборной кампании «Единая Россия» распространяла в Вологде листовки-вкладыши в паспорт с указанием: правильно заполненный бюллетень — это тот, который подан за кандидата партии власти.

Листовки-вкладыши были двух видов: на одной приведен пример голосования по партийным спискам, на другой в качестве примера указаны имена кандидатов от «Единой России» по одномандатным округам. Например, по Заречному округу «гуляла» листовка с именем кандидата Сергея Голубева, а по Восточному — с именем единоросса Олега Молодцова. (К слову, ни Голубеву, ни Молодцову этот прием не помог — в своих округах они проиграли самовыдвиженцам.)
