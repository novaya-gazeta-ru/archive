# Кремниевая долина открылась внезапно

*Письмо быстрого разумом ученика 11-го класса из села Верхнерусское «графу» Шувалову с просьбой о предоставлении 1 миллиона евро*

*[media: <p>
		Как раз к 300-летней годовщине со дня рождения Михайлы Васильевича Ломоносова в стране объявился новый самородок. Только не на Крайнем Севере, а на не менее крайнем Юге. Как выяснилось, рождать собственных Платонов и быстрых разумом Невтонов удается в селе Верхнерусское Ставропольского края. В частности, ученик 11-го класса местной школы изобретает новую операционную систему, которая должна стать конкурентом набившей уже оскомину Windows.</p>
	<p>
		В отличие от Ломоносова дитя Ставрополья не стало идти пешком в Москву на учебу. Президент Медведев сам явился к нему в День знаний и был, по-видимому, ошарашен прогрессом науки, осуществлявшимся независимо от строительства наукограда «Сколково». Пока Дмитрий Анатольевич приходил в себя и осмысливал перспективы, открывающиеся перед страной в связи с несанкционированным превращением села Верхнерусского в Силиконовую долину, быстрый разумом ставропольский Невтон попросил у президента на развитие проекта 1 млн евро. Обосновал он это, в частности, тем, что над проектом работают 200 программистов в различных странах мира, причем каждый из них желает получать зарплату.</p>
	<p>
		Удивительно, как быстро идея о пользе государственного финансирования для личного кармана овладевает массами. Совсем недавно пресса обсуждала удивительные оценки социологов, согласно которым студенты наши хотят работать не столько даже в нефтяном и газовом бизнесе, сколько на госслужбе, где сохраняются маленькие зарплаты, зато доступны становятся не мереные откаты. И вот выясняется, что даже школьники из отдаленных селений сегодня вполне осознают, как делаются в России настоящие деньги.</p>
	<p>
		Президент в ответ на просьбу о финансировании отделался шуткой. Однако не трудно себе представить конкретное обоснование проекта, которое нынешний Ломоносов мог бы направить в правительство. Выглядело бы оно примерно как хорошо известное письмо Михайлы Васильевича графу Шувалову о пользе стекла, составленное в стихах в 1752 году.</p>
	<p>
		<strong>Письмо о пользе бюджетного бабла к его высокопревосходительству первому вице-премьеру Игорю Ивановичу Шувалову, кавалеру Почетной грамоты Правительства РФ за большой личный вклад в решение задач социально-экономического развития страны.</strong></p>
	<p>
		Неправо о вещах те думают, Шувалов, // Которые бабло чтут ниже минералов, // Металлов, нефти, газа и икры, // Дающих нам бюджетные дары. // Казенное бабло, дотации, кредиты, // Инвестпрограммы дюже знамениты, // Поскольку их так просто распилить. // Не надо ничего производить, // Не надо торить на Ямал дорогу, // Не надо Exxon Mobil звать в подмогу, // Не надо строить «Северный поток». // Берешь бюджета маленький кусок // Согласно указанью президента // И, дождавшись удобного момента, // Изобретаешь Windows иль iPad, // Иль на худой конец велосипед. // Не важно что, поскольку эти штуки // Есть не товар, а лишь плоды науки, // Которою гордится славный росс. // Не важно, есть ли на наш Windows спрос. // Мы сделаем единственный iPad, // Его получит только президент. // И пусть тогда попробует Степашин // Узнать, куда девались деньги наши. // Поверь, Шувалов, с помощью казны // Прославятся отечества сыны. // Из недр казны на свет произошло // Любезное дитя — бюджетное бабло. // Увидев, смертные о как ему дивились. // Подобное тому сыскать, наверно, тщились // И в малом бизнесе, и даже в IPO. // Но всех затмит бюджетное бабло // По простоте и скорости дохода. // В нем кроется младых, // Тот будет всем пример, дожив власов седых.</p>]*
