# Анонс

*27 марта в рамках цикла «Нездешние вечера» в Театре Музыки и Поэзии п/р Елены Камбуровой состоится творческий вечер Юрия Арабова «Механика судьбы»*

Юрий Арабов — кинодраматург, писатель, культуролог. Полноправный соавтор авторского кино Александра Сокурова, начиная с дебютной ленты «Одинокий голос человека» по Андрею Платонову. Один из самых продуктивных сценаристов, одна из самых интригующих личностей российского кинематографа, одновременно самая непубличная из его фигур.

Не раз обращался к сюжетам Серебряного века и эпохи модерн, примером чему может служить мистический триллер «Господин оформитель», снятый в 1988 году, — пожалуй, самая известная из «несокуровских» работ Арабова.

Арабов является одним из организаторов неформального клуба «Поэзия» в Москве. С 1992 года заведует кафедрой кинодраматургии во ВГИКе.

Лауреат премий им. Аполлона Григорьева, «Ника», «Золотой овен», премии Каннского кинофестиваля.
