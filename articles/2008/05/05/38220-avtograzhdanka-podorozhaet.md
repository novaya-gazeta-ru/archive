# «Автогражданка» подорожает.

Российский союз автостраховщиков предложил увеличить базовый тариф ОСАГО для граждан на 22 процента — с 1980 до 2417 рублей. Тариф для такси должен вырасти в 2,4 раза — с 2965 до 7049 рублей. Страховка автобусов и троллейбусов также будет дороже. Глава Ростехнадзора Илья Ломакин-Румянцев согласился с тем, что тариф ОСАГО необходимо повысить. По его прогнозам, увеличение стоимости полиса может произойти уже этой осенью.
