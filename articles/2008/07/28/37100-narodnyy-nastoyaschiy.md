# Народный, настоящий

*Не стало одного из самых обаятельных российских актеров*

Ушел из жизни замечательный трагикомический актер Михаил Пуговкин. Народный артист — в самом прямом смысле этих слов. Без него «Свадьба в Малиновке», «Сoлдат Иван Бровкин», «Операция «Ы», «Иван Васильевич меняет профессию», «Два капитана», «Девчата», «12 стульев» были бы совсем другими.

Долгие годы артист болел сахарным диабетом. Прибывшие в очередной раз врачи не смогли его спасти.

Похороны Михаила Ивановича состоятся на Ваганьковском кладбище во вторник.
